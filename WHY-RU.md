# Зачем greedy-token

**English version:** [WHY.md](WHY.md)

Не судите каждый ответ. Сначала спросите: **нужна ли модель вообще?**

LLM-as-a-judge оценивает, насколько хороша генерация. Greedy-token гоняет задачу по лестнице дешёвых исполнителей — и только потом зовёт Claude / Cursor.

| | |
|--|--|
| **~97%** дешёвый путь | **~3%** дорогая LLM |
| **~$2.2k** экономия / мес* | **~$26k** экономия / год* |

\*Иллюстративный P&L для небольшой AI-компании (допущения внизу).

---

## Лестница

Первый подходящий tier побеждает. Дорогая модель — **последний** шаг, не первый. Skills, Rules, RAG и ADR ведут, куда слать задачу.

| Шаг | Что | Стоимость |
|-----|-----|-----------|
| **1. Tool** | `rg` / `jq` и другие CLI — нативные бинарники на **Rust**. Поиск и разбор почти за $0. | ~$0 LLM |
| **2. Python** | Скрипты и **crystallize**: повторяемая процедура один раз из LLM → дальше детерминированный Python. | ~$0 LLM |
| **3. Cheap / local LLM** | **Ollama** (и аналоги) — classify, audit, bulk. Работает без Claude (например **Continue.dev**). Локальный inference **медленный**, поэтому сначала tool / Python / RAG. | дёшево · медленнее frontier |
| **4. Expensive LLM** | Только здесь: **Claude / Cursor** — wiring, архитектура, то, что не закрыли шаги 1–3. | дорого · ~3% |

### Слой знаний (не платный шаг)

**Skills · Rules · RAG · ADR** — канон, который кормит лестницу: куда роутить, что уже решено, какой паттерн читать без Claude.

| | |
|--|--|
| **Skills** | Повторяемые процедуры агента (crystallize, sync-meta, …) |
| **Rules** | Жёсткие ограничения: scope, stands, greedy-token до Grep |
| **RAG** | Lookup паттернов и флагов из docs без полного чата |
| **ADR** | Архитектурные решения — не переизобретать в каждом чате |

Типичный путь:

```text
Skills / Rules / RAG / ADR
  → rg / jq (Rust)
  → crystallize / Python
  → Ollama
  → и только потом Claude / Cursor
```

## Сравнение

Маленькая AI-компания · 8 инженеров · ~14 000 запросов агентов / месяц

| Что сравниваем | LLM-as-a-judge | Greedy-token | Judge, $ | Greedy-token, $ |
|----------------|----------------|--------------|----------|-----------------|
| Вопрос | Насколько хорош ответ? | Нужна ли модель? | — | — |
| Агенты | Сразу Claude / Cursor | Skills/Rules/RAG/ADR → rg·jq (Rust) → Python → Ollama → Claude/Cursor | $550 | $30 |
| Проверки | Вторая модель на каждый серьёзный прогон | Жёсткие asserts + judge на релизах | $2 150 | $515 |
| Итого стек | Дорогие агенты + постоянный judge | Роутинг + лёгкий offline-eval | **$2 700** | **$540** |

### Стек A — классика · $2 700 / мес

Всё через дорогую LLM, плюс golden dataset и LLM-as-a-judge на каждый серьёзный прогон. Хорошо для качества **продукта** — дорого как default для **внутренней** разработки.

| Строка | Стоимость |
|--------|-----------|
| Дорогая LLM (Claude / Cursor) · 100% | $550 |
| Judge + люди | $2 150 |

### Стек B — greedy-token · $540 / мес

Skills, Rules, RAG и ADR задают канон. Дальше лестница тиров. В конце — **та же** карточка «Дорогая LLM» (Claude / Cursor), что в стеке A: до неё доходит **~3%** запросов, а не 100%.

| Строка | Стоимость |
|--------|-----------|
| Skills · Rules · RAG · ADR | ~$0 |
| Tool (rg/jq · Rust) + Python crystallize + Ollama · ~97% | ~$14 |
| Дорогая LLM (Claude / Cursor) · ~3% — как в A | ~$17 |
| Offline-eval + релизный judge | $515 |

## Понятные уравнения

Все суммы — **USD / месяц**. Подставьте свои цифры — формула та же.

### 1. Стоимость агентов

Без роутинга (всё в дорогую модель):

```text
стоимость_агентов = запросы × цена_дорогой_модели
14_000 × $0.04 = $550
```

С greedy-token (лестница тиров):

```text
стоимость_агентов = запросы × (3% × Claude/Cursor + 97% × tool/Python/Ollama)
14_000 × (~$0.002) ≈ $30
```

Канон = Skills / Rules / RAG / ADR · tool = rg/jq (Rust) · Python = crystallize · cheap LLM = Ollama · expensive = Claude / Cursor.

### 2. Стоимость проверки качества

Постоянный LLM-as-a-judge:

```text
judge = (кейсы × прогоны × $оценки) + зарплата_поддержки
(250 × 40 × $0.015) + $2_000 = $2_150
```

Greedy-token: asserts + judge только на релизах:

```text
eval = лёгкая_поддержка + релизный_judge
$500 + $15 ≈ $515
```

### 3. Экономия

```text
экономия = стек_A − стек_B
$2_700 − $540 ≈ $2_160 / месяц
$2_160 × 12 ≈ $26_000 / год
```

Главный кусок экономии — **люди**, не API judge (~$150): не нужно держать штат на непрерывной LLM-оценке ($2 000).

## Честно

Greedy-token **не** заменяет LLM-as-a-judge для модели, которую вы продаёте. Judge оставьте на **релизах продукта**. Внутри команды:

```text
Skills / Rules / RAG / ADR → rg/jq (Rust) → Python crystallize → Ollama → и только потом Claude / Cursor
```

### В том числе полностью локально

Можно работать **без доступа к дорогой LLM** — например через **Continue.dev** + Ollama / локальный hub. Tool (`rg`/`jq`) и Python crystallize закрывают поиск и повторы без модели; локальная LLM остаётся запасным тиром.

Бонус не только в цене: **локальные модели медленные**, а rg / скрипты / RAG отвечают заметно быстрее.

## Допущения (иллюстрация)

- 8 инженеров · ~14k запросов / месяц  
- Дорогой запрос $0.04 · дешёвый $0.001  
- ~97% cheap (форма живого трафика greedy-token)  
- Judge golden 250 × 40 прогонов · 0.2 FTE на judge vs 0.05 FTE на offline-eval  
- Сиденья Cursor (~$320 / мес) в обоих стеках одинаковы и в экономию **не** входят
