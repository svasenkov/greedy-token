# Зачем greedy-token

**English version:** [WHY.md](WHY.md)

В типичном AI-сетапе почти всё уезжает в дорогую модель — Claude, Cursor, что угодно. А чтобы спать спокойнее, сверху вешают ещё одну модель, которая *судит* первую.

Так тоже можно. Только вы платите frontier-цены за задачи, которым модель не нужна: найти строку, прогнать проверку, вспомнить флаг, который уже описан в доке.

**Greedy-token сначала задаёт простой вопрос: а модель вообще нужна?**

---

## Суть в одном абзаце

Лёгкую работу отдаём быстрым и дешёвым инструментам. Дорогой чат оставляем на сложное. LLM-as-a-judge — для продукта, который вы продаёте, а не для каждого внутреннего grep.

На форме трафика, похожей на нашу живую, это примерно **97%** запросов без frontier-модели и **~3%** с ней. Для небольшой команды иллюстративный разрыв со стеком «всё дорогое + постоянный judge» — порядка **~$2k / месяц** или **~$26k / год** (допущения внизу — подставьте свои цифры).

---

## Как это едет по ступеням

Представьте лестницу. Первая ступенька, которая справляется, побеждает. Дорогая модель — *последняя*.

1. **Tools** — `rg`, `jq` и компания. Нативные бинарники на **Rust**. Поиск и разбор почти бесплатно и *быстро*.
2. **Python** — особенно после **crystallize**: один раз решили задачу с LLM, вытащили повторяемую процедуру в скучный скрипт — и больше не платим за одно и то же.
3. **Дешёвая / локальная LLM** — **Ollama** и аналоги. Нормально для classify / audit / bulk, когда нужен язык, но не нужен frontier. Работает и без Claude (например **Continue.dev**). Локальные модели **медленные**, поэтому сначала tools и скрипты.
4. **Дорогая LLM** — **Claude / Cursor**. Wiring, архитектура, спорные решения. Только если ступени выше не закрыли задачу.

Под всем этим — **слой знаний**. Это не отдельный платный API, а канон, чтобы команда не изобретала велосипед в каждом чате:

| | |
|--|--|
| **Skills** | «Вот как мы всегда делаем X» (crystallize, sync-meta, …) |
| **Rules** | Жёсткие рельсы: scope, стенды, поиск через greedy-token, а не сырой Grep |
| **RAG** | Короткие ответы из доков — паттерны, флаги — без полного эссе агента |
| **ADR** | Решения, которые уже приняли, чтобы не переспорить их заново |

На практике:

```text
Skills / Rules / RAG / ADR
  → rg / jq (Rust)
  → crystallize / Python
  → Ollama
  → и только потом Claude / Cursor
```

## Два стека, одна компания

Возьмём маленькую AI-лавку: **8 инженеров**, около **14 000** запросов к агентам в месяц.

### Стек A — классика · ~$2 700 / мес

Всё через дорогую модель. Плюс golden-набор и LLM-as-a-judge на каждый серьёзный прогон.

Отлично для качества **продукта**. Тяжело как default для **внутренней** рутины.

| | |
|--|--|
| Дорогая LLM (Claude / Cursor) на ~100% запросов | $550 |
| Judge + люди, которые это поддерживают | $2 150 |

### Стек B — с greedy-token · ~$540 / мес

Та же карточка «дорогая LLM», что в стеке A — Claude / Cursor никуда не делись. Просто до них доходит **~3%** трафика, а не всё подряд. Skills / Rules / RAG / ADR уводят остальное вниз по лестнице. Judge — на **релизах**, не на каждом внутреннем прогоне.

| | |
|--|--|
| Skills · Rules · RAG · ADR | ~$0 |
| Tools + Python crystallize + Ollama (~97%) | ~$14 |
| Дорогая LLM (~3%) — как в A, тонкий срез | ~$17 |
| Лёгкие offline-проверки + релизный judge | $515 |

## Считалка без тумана

Все суммы — **доллары в месяц**. Меняйте входы, форма остаётся.

**Агенты без роутинга**

```text
запросы × цена_дорогой_модели
14_000 × $0.04 = $550
```

**Агенты с лестницей**

```text
запросы × (3% × дорогое + 97% × дешёвое)
14_000 × (~$0.002) ≈ $30
```

**Постоянный judge**

```text
(кейсы × прогоны × $за_оценку) + время_человека
(250 × 40 × $0.015) + $2_000 = $2_150
```

**Лёгкий eval + релизный judge**

```text
$500 + $15 ≈ $515
```

**Разница**

```text
$2_700 − $540 ≈ $2_160 / месяц
≈ $26_000 / год
```

Главная дыра в бюджете — не API judge (~$150), а люди на бесконечной ленте «оцени каждый ответ».

---

## Чего мы не обещаем

Greedy-token **не** заменяет LLM-as-a-judge для модели, которую вы продаёте клиентам. Оставьте judge на **релизах продукта**.

Он убирает другую привычку: платить frontier-цены за поиск, diff и проверки, которые репозиторий уже умеет делать сам.

### Можно совсем локально

Нет ключа от Claude? **Continue.dev** + Ollama (или локальный hub). Tools и crystallize-скрипты всё равно работают. Локальная модель — запасной ход, не парадный вход.

И да: даже когда всё локально, лестница помогает — **локальные модели ползут**, а `rg` и скрипты нет.

## Допущения (чтобы было с чем спорить)

- 8 инженеров · ~14k запросов / месяц  
- Дорогой запрос $0.04 · дешёвый $0.001  
- ~97% cheap — форма живого трафика greedy-token  
- Judge golden: 250 кейсов × 40 прогонов · 0.2 FTE против 0.05 FTE на offline-eval  
- Сиденья Cursor (~$320 / мес) в обоих стеках одинаковы и в экономию **не** входят
