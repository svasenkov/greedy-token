# Зачем greedy-token

**English version:** [WHY.md](WHY.md)

В типичном сетапе почти всё уезжает в Claude / Cursor, а сверху вешают ещё одну модель, которая *судит* первую. Так можно — только вы платите frontier-цены за grep, проверки и lookup, которые репо уже умеет само.

**Greedy-token сначала спрашивает: а модель вообще нужна?**

```text
Skills / Rules / RAG / ADR
  → rg / jq (Rust) → Python crystallize → Ollama
  → и только потом Claude / Cursor
```

Tools и скрипты — дёшево **и** быстро. Локальные LLM (Ollama, Continue.dev) работают без дорогой модели, но медленные — поэтому они после tools, а не вместо них. Дорогой чат — на сложные ~3%. LLM-as-a-judge — на **релизах продукта**, не на каждом внутреннем прогоне.
