Модели и ставки

Матрица: greedy vs без greedy

«С greedy, tok» = agent overhead ~17,043 (измерен calibrate: rules + system + schemas + reply) + payload исполнителя — greedy-вызов не бесплатен, ход агента платится. Wall включает старт CLI (~200ms). Конверт tool-вызова (~±60 tok: Read-обёртка у наивного, Bash/MCP у greedy) не учтён симметрично — сокращается. Красные строки — честный минус, saved < −50 tok (ниже — шум аппроксимации): на 100B-фикстурах route-карта (150–800 tok) дороже самого файла; промахи платят и наивный ход, и шапку роута. «Intercept, tok» — тот же запрос в intercept-режиме: ход агента не случается вообще, saved ≈ весь наивный ход (у ollama −~115 eval-токенов локальной модели, billing $0). Стоимость по input-ставке.

Большие объёмы — где greedy реально окупается

oh = agent overhead воркспейса: workshop 17,043 / monorepo ~37,450. Наивный pull — измеренный объём (байты/4), который агент прочитал бы: 1.2MB JSONL, 4.9MB usage-лог, guide.md, git log. Красная строка — после фикса --compact: 7.2KB ≈ 1.8k tok vs naive 0.9k — листинг всё ещё лёгкий минус; «что изменилось» выигрывает. run CLI тоже применяет args_from_prompt (F4 закрыт): plan_run приклеивает derived-argv к команде — compact доезжает и по hook/intercept, и по run --execute.

Живые прогоны — headless CLI devin -p (2026-10-02)

96 легов: 6 пар × 4 модели × 2 руки × 2 прогона. Каждый лег — свежая сессия devin -p; токены — фактические из sessions.db (input + cache_read + cache_create + output). Naive-нога в нейтральном /tmp (без .greedy-token.yaml); greedy-нога в workshop через CLI. Главный факт: дисперсия доминирует — медиана saved ≈ +1.6k tok, а вся масса экономии в хвосте: когда наивный агент спиралится (E-opus +1.49M tok / ~$1.5, E-swe +1.02M — бесплатная модель спиралится чаще всех: 41 тула + попытка записи файлов при «код не пиши»), связанный greedy-путь ограничивает ущерб. Систематически: D (llm invoke --user-file) экономит у kimi/opus стабильно +14k/+22k — одна нога exec вместо read+exec; E/F (route → «ответь сам») аддитивны по построению и ведут себя как лотерея. Advisory-режим ≠ гарантия экономии на уровне агента; гарантированная экономия — intercept (весь ход не случается). $ — реальная разбивка по ставкам модели (in + cache_create по input-ставке, cache_read по cached, output по output); swe-2-max — free.

Матрица исполнителей — ollama classify (2026-10-02)

llm invoke --profile X --user-file lab/users.json, без агента. cold — первый вызов (загрузка модели в VRAM), warm — второй. «JSON» — вывод содержит структуру с id/email; «ловит id:2» — корректно помечает запись без email. Ремоуты недоступны: qa.guru — timeout, box2 — 401 без кредов. Вывод: 7b локально — лучший по формату (чистый JSON) и цене ($0); gpt-oss:20b не удерживает classify-инструкцию.
