Итог

Как читать Три колонки токенов: «без greedy» (полный наивный ход) vs «с greedy» (тот же ход агента + payload исполнителя) → Saved = их разница. Футерное «saved ~17k» верно только при hook-режиме intercept — когда LLM-ход не случается вовсе; в advisory/MCP overhead платится. Футер сам печатает оба числа: «saved ~N (if intercept; turn-shared otherwise ~M)», а события usage.jsonl несут поле hook_mode. $ — по input-ставке (saved = непрочитанный контекст; output <5%). После живых прогонов заменить base/overhead фактом из IDE usage.
